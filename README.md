# SCMusic — versions

APK signés de **SCMusic**, lecteur de musique local, libre (GPL-3.0) et sans services Google, pour Android.

L'application installée vérifie ce dépôt et propose elle-même les mises à jour.
Pour une première installation : télécharge le fichier `SCMusic-x.y.z.apk` de la [dernière version](../../releases/latest)
et ouvre-le sur le téléphone (Android demande d'autoriser l'installation depuis cette source).

Empreinte du certificat de signature (SHA-256) :
